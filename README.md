# Sistema de Registro de Incidencias

Aplicación web sencilla para registrar y listar incidencias reportadas por usuarios.
Proyecto de la asignatura Gestión de la Configuración del Software (UNEMI).

## Funcionalidades
- Registro de incidencias (título, descripción, estado)
- Listado de incidencias registradas

## Tecnologías
HTML5, CSS3, JavaScript, Git, GitHub, GitHub Actions

## Cómo ejecutarlo
1. Clonar el repositorio:
   `git clone https://github.com/USUARIO/sistema-incidencias.git`
2. Entrar a la carpeta: `cd sistema-incidencias`
3. Abrir `index.html` en el navegador (o usar la extensión Live Server de VS Code).

## Flujo de trabajo
- `main`: rama estable, solo recibe cambios mediante Pull Request.
- `feature/*`, `fix/*`, `docs/*`: ramas de trabajo.
- Versionamiento semántico: MAJOR.MINOR.PATCH.
